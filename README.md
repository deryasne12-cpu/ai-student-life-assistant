# AI-Powered Student Life Assistant

## Overview
This project is an AI-based system designed to help students manage their mood, productivity, and daily study planning.

## Features
- Mood detection using NLP
- Productivity prediction using machine learning
- Smart suggestion system
- Daily planning assistant

## Problem
Students often struggle with stress, lack of focus, and inefficient time management. Existing tools do not combine emotional state and productivity analysis.

## Technologies
- Python
- TextBlob / VADER (NLP)
- Scikit-learn (Machine Learning)
- Streamlit (User Interface)

## Project Structure
- src/ → AI modules
- app/ → user interface
- data/ → datasets
- docs/ → documentation

## Setup
1. Clone the repository
2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Run the app:
   ```
   streamlit run app/app.py
   ```
